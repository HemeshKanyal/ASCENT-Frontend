# Contributing to ASCENT-Frontend

Thank you for your interest in contributing to ASCENT-Frontend! We welcome contributions from everyone. By participating in this project, you agree to abide by our code of conduct.

## 🤝 Code of Conduct

We are committed to providing a friendly, safe, and welcoming environment for all. Please be respectful and considerate in your interactions.

## 🚀 How to Contribute

### 1. Fork and Clone

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone <your-fork-url>
   cd workoutApp
   ```

### 2. Set Up Environment

1. Install dependencies:
   ```bash
   npm install
   ```

### 3. Create a Branch

Create a new branch for your feature or bug fix:
```bash
git checkout -b feature/my-new-feature
# or
git checkout -b fix/bug-description
```

### 4. Make Changes

- Write clear, maintainable code.
- Ensure your changes work as expected.
- Follow the existing project structure.

### 5. Commit and Push

Commit your changes with descriptive messages:
```bash
git commit -m "feat: add new workout tracking component"
git push origin feature/my-new-feature
```

### 6. Submit a Pull Request

1. Go to the original repository on GitHub.
2. Click "New Pull Request".
3. Select your branch and fill in the PR details.
4. Wait for review and address any feedback.

## 💻 Coding Standards

- **TypeScript:** Use strong typing where possible. Avoid `any`.
- **Formatting:** Use standard Prettier/ESLint configurations if available.
- **Component Structure:** Keep components small, focused, and reusable.
- **File Naming:** Use `camelCase` for files and `PascalCase` for React components.

Thank you for contributing!
